# Prácticas de PROG1

Una carpeta por práctica: `asignaturas/prog1/practicas/<nn-nombre>/` con

- `enunciado.md` (o el PDF del enunciado),
- tu código (`.cpp`).

Luego, en Claude Code: «ayúdame con la práctica 1» → skill **tutor-practicas** (te da pistas y revisa
tu código, pero **no** te escribe la solución salvo que se la pidas explícitamente).

`00-ejemplo/` es un ejemplo para probar la skill: bórralo cuando quieras.
